Deep Packet Analyzer with Deep Packet Inspection (DPI)


Overview
Packet Analyzer is a C++-based network traffic analysis project that uses a Deep Packet Inspection (DPI) engine to process and inspect network packets stored in PCAP files. The project aims to explore network packet processing, traffic inspection, and fundamental network security concepts through practical implementation.

The application takes a PCAP file as input, processes the captured network traffic using its implemented inspection logic, and generates an output PCAP file for further examination. It provides an opportunity to understand how packet capture files can be processed programmatically and how network traffic inspection contributes to network analysis.


Features
1. PCAP File Processing:** Works with packet capture files containing recorded network traffic.
2. Deep Packet Inspection:** Includes a DPI engine for examining packet data according to the implemented logic.
3. Network Traffic Analysis:** Supports the processing and inspection of captured network packets.
4. Output PCAP Generation:** Produces an output packet capture file for further analysis.
5. C++ Implementation:** Uses C++ to implement the packet processing engine.
6. Practical Learning:** Demonstrates concepts related to network communication, packet inspection, and network security.


Technologies Used
1. C++
2. Deep Packet Inspection (DPI)
3. PCAP (Packet Capture)
4. Network Traffic Analysis


How It Works
1. A PCAP file containing captured network traffic is provided as input.
2. The DPI engine processes the input file.
3. Packet data is examined according to the inspection logic implemented in the project.
4. The processed traffic is written to an output PCAP file.
5. The generated output can be examined using compatible packet analysis tools.


Getting Started
Prerequisites
1. A Windows environment or another supported environment compatible with the project.
2. The compiled DPI engine executable, or the tools required to build it from the source code.
3. A valid PCAP file for testing.


Running the Project on Windows
Open PowerShell in the project directory and execute:
`powershell
.\dpi_engine.exe test_dpi.pcap output.pcap
`


Command explanation:**

1. `dpi_engine.exe` - The compiled DPI engine.
2. `test_dpi.pcap`  - The input packet capture file.
3. `output.pcap`    - The output file generated by the program.

Replace the input filename with another compatible PCAP file when required.
